## Overview

The **Advanced Extensibility SKU** is a premium add-on for Auth0 Enterprise customers. It is designed for organizations with complex identity requirements that exceed the standard limits of [Auth0 Actions](https://auth0.com/docs/customize/actions), Rules, and Hooks.

This SKU provides higher execution thresholds, increased secret storage, and enhanced isolation for custom code execution, ensuring that your identity pipeline scales with your most demanding applications.

<Info>
  The Advanced Extensibility SKU requires an existing Enterprise subscription. Contact your Account Executive to enable these features in your tenant.
</Info>

## Use Cases

### 1. Complex User Migration
Perform "Lazy Migration" from legacy databases where the password hashing or data enrichment requires high-latency calls to on-premise systems.

### 2. Multi-Factor Orchestration
Integrate with 3rd-party risk engines (e.g., LexisNexis, BioCatch) that require intensive data processing or multiple round-trips before allowing a login.

### 3. Real-time Data Enrichment
Query multiple external CRMs (Salesforce, HubSpot) and ERPs during the login flow to inject granular custom claims into the ID Token without fear of execution timeouts.

## Technical Implementation

When the Advanced Extensibility SKU is active, no code changes are required to your existing Actions. The underlying infrastructure automatically adjusts the runtime quotas.
