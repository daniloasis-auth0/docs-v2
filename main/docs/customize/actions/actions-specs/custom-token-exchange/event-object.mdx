---
description: Learn about the custom-token-exchange Action trigger's event object, which provides contextual information about the trigger execution.
title: 'Actions Triggers: custom-token-exchange - Event Object'
---

The `event` object for the custom-token-exchange Actions trigger provides contextual information about the trigger execution.

<table>
  <thead>
    <tr>
      <th>Property</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    
    <tr>
      <td>
        <code>event.client</code><br/>
      </td>
      <td>
        Information about the Client with which this transaction was initiated.<br/>
        Includes the following properties:
        <ul>
          <li>
            <code>client_id</code> <em>String</em> — The client id of the application the user is logging in to.
          </li>
          <li>
            <code>metadata</code> <em>Dictionary</em> — An object for holding other application properties.
          </li>
          <li>
            <code>name</code> <em>String</em> — The name of the application (as defined in the Dashboard).
          </li>
        </ul>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.organization</code><br/>
        <p><em>(Optional)</em></p>
      </td>
      <td>
        Details about the Organization associated with the current transaction.<br/>
        <em>Dictionary, undefined</em>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.request</code><br/>
      </td>
      <td>
        Details about the request that initiated the transaction.<br/>
        <em>Dictionary, undefined; continentCode?: string, undefined; countryCode?: string, undefined; countryCode3?: string, undefined; countryName?: string, undefined; latitude?: number, undefined; longitude?: number, undefined; subdivisionCode?: string, undefined; subdivisionName?: string, undefined; timeZone?: string, Dictionary, undefined; ip: string; language?: string, undefined; method: string; user\_agent?: string, undefined; }</em>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.resource_server</code><br/>
      </td>
      <td>
        Details about the resource server to which the access is being requested.<br/>
        Includes the following properties:
        <ul>
          <li>
            <code>identifier</code> <em>String</em> — The identifier of the resource server. For example: `https://your-api.example.com`.
          </li>
        </ul>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.tenant</code><br/>
      </td>
      <td>
        Details about the Tenant associated with the current transaction.<br/>
        Includes the following properties:
        <ul>
          <li>
            <code>id</code> <em>String</em> — The name of the tenant.
          </li>
        </ul>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.transaction</code><br/>
      </td>
      <td>
        Details about the current custom token exchange transaction.<br/>
        <em>{ requested\_scopes: string[]; requested\_token\_type: string, null; subject\_token: string; subject\_token\_type: string; }</em>
      </td>
    </tr>
    <tr>
      <td>
        <code>event.secrets</code><br/>
      </td>
      <td>
        Secret values securely associated with this Action.<br/>
        <em>Secrets</em>
      </td>
    </tr>
  </tbody>
</table>
